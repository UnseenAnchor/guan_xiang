# 观象 · 八字排盘

观象是一个本地优先的四柱排盘与传统命理知识展示网页。历法计算基于 `lunar-python`，排盘规则和知识数据同步自 `CYBZ_reverse` 的已验证版本。

当前版本：`0.3.0`

## 启动

```bash
pip install -r requirements.txt
python web_server.py
```

访问 <http://127.0.0.1:8787>。

## 时间口径

- 默认按出生记录中的中国标准时间排盘。
- 出生地和经纬度均为选填。
- 只有用户主动勾选“使用真太阳时校正排盘”时，才会向引擎传入经度。
- 启用真太阳时但没有经度时，请求会被拒绝，不会静默使用北京经度。
- 启用后会展示校正前后日期时间及发生变化的四柱。
- 当前离线地点库只覆盖中国行政区，按 `Asia/Shanghai`（UTC+8）处理；海外地点需要时区与夏令时支持后再开放。

## 当前网页已展示

- 公历与农历输入，含闰月检查
- 省、市、区县及县级市离线地点搜索
- 四柱、十神、藏干、纳音、空亡、十二长生
- 天干五合与地支刑冲合会
- 完整大运、未来五年流年与运年参照
- 神煞、胎元、命宫、身宫
- 120项月令正文与十干古籍描述
- 可选真太阳时校正及四柱差异对比
- 命盘章节导航，以及默认折叠的旺衰、格局、取用实验推演
- 独立“黄历 · 观时”页面，展示建除、黄道黑道、九星、二十八宿、宜忌、节气、彭祖百忌、胎神、方位与冲煞

黄历可从顶部导航进入，也可直接访问 <http://127.0.0.1:8787/almanac>。

## API

- `POST /api/chart`：排盘结果；`实验推演` 字段使用版本化 Web Schema，包含证据、来源和边界说明。
- `GET /api/almanac?date=2026-08-12`：指定公历日期的版本化黄历数据。
- `GET /api/lunar-year?year=1990`：农历月份、天数与闰月信息。
- `GET /api/health`：应用版本和服务状态。

扩展知识文件已加载并统计；没有确定匹配规则的短语不会被随机归入个人命盘。

## 命令行

```bash
# 标准时间，不进行真太阳时校正
python main.py 1990 5 15 10 30 1

# 显式传入经度后启用真太阳时校正
python main.py 1990 5 15 10 30 1 --lon 113.3
```

## 数据来源分层

- `历法计算`：由 `lunar-python` 与本地基础表生成。
- `逆向确认`：来自 CYBZ_reverse 对目标 App 行为和数据结构的验证。
- `古籍参照`：《穷通宝鉴》《滴天髓》《三命通会》《协纪辨方书》等补充资料。
- `实验模型`：旺衰、格局、喜忌、用神、病药和通关等程序化推断。

古籍补充不等同于 APK 原文；实验模型不代表唯一命理结论。

## 已知边界

- 晚子时按逆向确认的目标 App 行为换至次日日柱。
- 真太阳时在当前网页中仅按中国标准时间处理。
- 五行数量只表示结构计数，不等同于旺衰和喜用神。
- 《三命通会》模块属于古籍条文的简化匹配，不是完整个人论命引擎。
- 旺衰、格局、喜忌和用神属于实验模型，只在默认折叠且明确标注的区域展示；权重与取法不代表唯一结论。
- 当前前端仍由 V2 输入层和 V3 结果覆盖层共同组成；这是现役实现，但不是最终模块结构。
- 桌面、平板、手机三档专项排版验收尚未执行，现阶段仅保留既有响应式规则并完成主流程浏览器验收。

本项目用于传统文化研究与娱乐体验，不构成医疗、法律、投资或人生决策建议。
