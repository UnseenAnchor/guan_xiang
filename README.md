# bazi-engine — 八字排盘引擎（开源）

一个可本地运行的传统四柱排盘与命理知识展示工具。
**历法计算基于 lunar-python，命理规则和展示数据保存在本地。**

## 特性

- **四柱排盘**：年柱立春分界 / 月柱节气分界（五虎遁）/ 日柱儒略日 mod 60 / 时柱五鼠遁
- **十神 / 藏干 / 纳音 / 空亡 / 十二长生**（本地数据包含 100 条十神表、120 条长生表和 60 条纳音表）
- **神煞**：30+ 种标准查法（天乙/文昌/禄/羊刃/驿马/桃花/华盖/将星/劫煞/亡神/灾煞/红鸾/天喜/孤辰/寡宿/天德/月德/天医/元辰/丧门/吊客/披麻/勾绞/三奇/魁罡/孤鸾/阴差阳错/八专/九丑/十灵/十恶大败/六秀/四废/天转/地转/天赦/金神/童子煞…）
- **断语分析**：月令断语 120 + 十神断语 167 + 日柱坐支论 120 + 性格断语 211（本地数据）
- **刑冲合会**：天干五合 / 地支六合·三合·半合·六冲·三刑·六害·相破·自刑·三会
- **真太阳时**：经度时差 + 均时差校正
- **大运 / 流年**：顺逆排法 + 起运 + 运年断语
- **老黄历**：建除值星 / 黄道黑道十二神 / 二十八宿 / 九星 / 彭祖百忌 / 胎神 / 宜忌

## 安装

```bash
pip install lunar-python
```

## 使用

```bash
# CLI
python main.py 1990 5 15 10 30 1        # 年 月 日 时 分 性别(1男/0女)
python main.py 1988 8 8 20 0 0          # 默认男

# 指定经度(真太阳时, 默认北京116.4)
python main.py 1990 5 15 10 30 1 --lon 113.3
```

```python
from bazi.engine import build_chart, render_text

chart = build_chart(1990, 5, 15, 10, 30, 0, sex=1, longitude=116.4)
print(render_text(chart))

# 结构化数据
chart['四柱']   # 年/月/日/时 柱详情(藏干/十神/纳音/空亡/长生)
chart['神煞']   # [(神煞名, 所在柱, 说明)]
chart['分析']   # [(标题, 断语)]
chart['刑冲合会']
chart['大运'] / chart['流年']
chart['真太阳时']
```

```python
# 老黄历
from bazi.huangli import get_huangli
print(get_huangli(2024, 2, 10))
```

## 已知边界

- 晚子时流派：日柱不换、时柱按次日起时（与多数排盘实践一致）
- 运年断语为基于标准命理规则的近似实现
- 身强弱/用神/格局喜忌未实现（主观推断层）
